# Zotero_Vademecum_Citation_Style
A repository for the history citation style at the University of Konstanz according to the Vademecum. 
For more information see : https://www.geschichte.uni-konstanz.de/studium/ba-geschichte/im-studium/vademecum/

This is not an official release from the History Department. It was created independently by a student.
